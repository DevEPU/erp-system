Analisis Sistem & Implementasi

Mengapa Fitur Ini Penting?

Pada industri plastic injection yang menggunakan Insert Molding (misalnya mencetak plastik dudukan kaca spion yang menyatu dengan sekrup logam), sering terjadi kegagalan proses (NG). Kegagalan ini dibagi menjadi dua kategori berdasarkan letak kerusakannya:

1. Cacat Material (NG Plastik) Plastik cetakan meluber, kurang matang, atau baret, namun sekrup logam (insert component) di dalamnya **tidak rusak**. Logam tersebut bisa dicabut kembali, dicuci, dan **dipakai lagi** di lantai produksi.

Efek Sistem: Hanya stok Resin yang berkurang permanen. Komponen dikembalikan ke stok lantai produksi (Gudang Produksi). Plastik rijek dihancurkan di Crusher (kembali ke MATKOM sebagai resin gilingan).
2. Cacat Komponen (NG Inserts) Sekrup logam berkarat, bengkok, dratnya dol, atau patah saat proses injection sehingga produk gagal total.

Efek Sistem: Plastik rijek masuk crusher (optional), sementara komponen logam yang cacat **dikembalikan ke Gudang Utama (MATKOM)** untuk diproses klaim ke vendor supplier. Produksi meminta komponen baru ke Gudang MATKOM tanpa memesan resin baru.

Rancangan Skema & Query Logika Baru

// 1. Struktur Skema Database Baru (Tabel Penampung Karantina Klaim) CREATE TABLE vendor_claims ( id BIGINT PRIMARY KEY AUTO_INCREMENT, production_output_id BIGINT, product_id BIGINT, qty_ng_component INT, status 'QUARANTINED' | 'RETURNED_TO_VENDOR', created_at TIMESTAMP, updated_at TIMESTAMP ); // 2. Query Transaksi untuk Kasus 1: NG Material // Hanya mengurangi Resin di Produksi, mengembalikan Komponen ke Produksi, dan memindahkan Resin NG ke Crusher START TRANSACTION; -- Potong seluruh material input dari Gudang Produksi UPDATE warehouse_stocks SET qty_stock = qty_stock - 0.48 WHERE product_id = 5 AND warehouse_id = 2; -- Resin UPDATE warehouse_stocks SET qty_stock = qty_stock - 10 WHERE product_id = 12 AND warehouse_id = 2; -- Component -- Kembalikan Komponen yang diselamatkan (10 Pcs) ke Gudang Produksi (Net Change = 0) UPDATE warehouse_stocks SET qty_stock = qty_stock + 10 WHERE product_id = 12 AND warehouse_id = 2; -- Giling Resin plastik NG dan kembalikan ke MATKOM (Regrind) UPDATE warehouse_stocks SET qty_stock = qty_stock + 0.48 WHERE product_id = 5 AND warehouse_id = 1; INSERT INTO crusher_logs (production_output_id, component_product_id, qty_ng_component, qty_regrind_resin, action) VALUES (14, NULL, 0, 0.48, 'Crushed and Returned to Matkom (Regrind)'); COMMIT; // 3. Query Transaksi untuk Kasus 2: NG Component // Komponen cacat dikembalikan ke MATKOM (karantina klaim) dan dibuatkan antrean re-issuance (Kirim Ulang) START TRANSACTION; -- Komponen Cacat (2 Pcs) dikembalikan ke MATKOM Karantina UPDATE warehouse_stocks SET qty_stock = qty_stock + 2 WHERE product_id = 12 AND warehouse_id = 1; -- Stok Karantina Vendor INSERT INTO vendor_claims (production_output_id, product_id, qty_ng_component, status) VALUES (15, 12, 2, 'QUARANTINED'); -- Buat tiket permintaan kirim ulang di sistem INSERT INTO material_issuance_replacements (wo_id, product_id, qty_requested, status) VALUES (3, 12, 2, 'PENDING'); COMMIT;
