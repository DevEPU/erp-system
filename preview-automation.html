Summary Perubahan Sistem

Rincian tabel database, API controller, rute Express, halaman Next.js, dan integrasi barcode.

Skema & Struktur Database Prisma Schema

  • mrps / mrp_details: Tabel penampung perencanaan kebutuhan material (BOM Explosion) berdasarkan PO Customer. Menyimpan rincian material yang didekati dan jumlah rilis Purchase Request.
  • planning_produksi: Rencana detail jalannya cetak mesin cetakan injection molding, mencakup setting target produk, status running, shift (1, 2, 3), dan operator.
  • vendor_delivery_schedules: Tabel estimasi kedatangan (ETD) material dari vendor berdasarkan PO Supplier untuk pemantauan ketersediaan stock sebelum mixing.
  • material_realizations: Pencatatan pengeluaran aktual raw material dari Gudang MATKOM ke area Mixing/Produksi.
  • production_outputs & crusher_logs: Mencatat realisasi cetakan injection dari mesin (OK vs NG) dan log crusher untuk plastik reject yang digiling ulang.

API Controllers & Routing Express Backend

  • MRP Logic Controller (src/controllers/mrpController.js): Menyediakan endpoint untuk `POST /mrp/generate` (mengambil seluruh detail produk pada PO Customer, meluncurkan peledakan BOM hingga menghasilkan total raw material yang dibutuhkan) serta `POST /mrp/:id/release` (menghasilkan Purchase Request otomatis bagi material yang stock-nya kurang).
  • Vendor Schedule Controller (src/controllers/vendorScheduleController.js): Mengelola status kedatangan (Pending, In Transit, Arrived). Saat diset `Arrived`, secara otomatis mengupdate tanggal aktual kedatangan dan mendebit stok masuk di gudang.
  • Production Controller (src/controllers/productionController.js): Menerima rilis QC Gate, mendebit produk OK ke persediaan Finished Goods, dan memilah produk NG untuk dimasukkan ke log Crusher daur ulang.

UI Halaman & Barcode Integration Next.js Frontend

  • Custom Hook (src/hooks/useBarcodeScanner.ts): Mendeteksi input berkecepatan tinggi (< 50ms per key) dari scanner keyboard emulator global, menyerap input secara pasif tanpa merusak input field teks biasa yang sedang aktif.
  • Halaman MRP (`/manufacturing/mrp`): Tampilan monitoring kebutuhan material berdasarkan PO Customer, visualisasi stok, dan tombol trigger Purchase Request otomatis.
  • Halaman Realisasi Bahan Baku (`/persediaan-barang/realisasi-bahan-baku`): Terintegrasi dengan `useBarcodeScanner` untuk menginput bahan transfer dari MATKOM ke Produksi secara cepat via scan kode lot.
  • Halaman QC Gate & Crusher (`/manufacturing/qc-gate`): Lembar checklist audit fisik kualitas produk injection serta menu pengalokasian bahan reject daur ulang.
